# MAIN vs. S&P 500 prostřednictvím SPY

Zdroj: [MAIN – Yahoo Finance](https://finance.yahoo.com/quote/MAIN/history/), [SPY – Yahoo Finance](https://finance.yahoo.com/quote/SPY/history/).

Období: 9. 10. 2007 až 7. 10. 2026; 4779 společných obchodních dnů. Denní závěrečné ceny upravené o dividendy a splity jsou normalizované na 100 na začátku společného období. Relativní změna upravené ceny slouží jako ukazatel celkové návratnosti se zahrnutými dividendami. Není to samostatná simulace obchodování a daní.

Konečný index MAIN: 1779.9975; růst +1679.9975 %. SPY: 702.7726; růst +602.7726 %. SPY je ETF sledující S&P 500, nikoli samotný index; zahrnuje vliv nákladů fondu. Bez daní a poplatků investora. Nejde o výkon všech BDC společností.

CSV obsahuje celou použitou řadu. Minulé výnosy nezaručují výnosy budoucí.
